# Changelog

## 2.0.0 — unreleased

The general edition: the agent works on any systemd Linux server, not one in particular.

- **Hardware from four optional sources:** the kernel's own sensors (hwmon and thermal zones), any vendor's BMC through ipmitool (read by unit and entity, with the BMC's own ok/warn/crit), SMART through smartctl (including drives behind a MegaRAID controller, never waking a sleeping disk), and NVIDIA GPUs.
- **Checks:** websites (with certificate expiry), ports, Minecraft and Steam (A2S) game servers, and status dashboards, each controllable through a unit or exact commands from the config.
- **New commands:** `brief` (for background checks) and `checks`; `check` replaces `game`, which stays as an alias.
- **Control has its own list.** Lifelines (ssh, the VPN, networking, docker) can only be restarted. A check's container is never stopped bare.
- **The sudo rules are generated by the agent from the argv it runs:** escaped, with no wildcards, fixed log counts and absolute paths. Reads are kept out of the auth log.
- **A new installer:** one file with the agent inside and a checksum; a dedicated `sentinel` account; detection of services, containers and hardware; `--detect`, `--check`, `--remove-key`, `--uninstall`.
- **One cache file per kind, each under its own lock**, so concurrent calls no longer overwrite each other.
- Protocol 2, additive: every protocol-1 field is still sent with the same shape.
